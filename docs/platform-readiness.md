# Platform Readiness & Asset Checklist — Re:NeWrld

Governed by **Project Growth v1.1.0** (Phase 13: Platform Completeness).

---

## 1. Web Branding & Browser Identity
- [ ] **Vector Logo**: Primary SVG brand mark supporting light and dark themes.
- [ ] **Favicons**: Multi-resolution `favicon.ico`, `favicon-16x16.png`, and `favicon-32x32.png`.
- [ ] **Apple Touch Icon**: `apple-touch-icon.png` (180x180 px) for iOS home screen bookmarks.
- [ ] **Social Sharing Cards**: Open Graph (`og:image` 1200x630 px) and Twitter card assets with accurate metadata.

---

## 2. Progressive Web App (PWA) Assets (if applicable)
- [ ] **Web App Manifest**: `manifest.json` configured with name, short_name, start_url, display mode, background_color, theme_color.
- [ ] **PWA Icons**: High-res icons (192x192 px, 512x512 px), including maskable icon variant.
- [ ] **Offline & Update Flow**: Service worker caching and offline fallback experience.

---

## 3. Mobile & App Store Assets (if applicable)
- [ ] **Android Launcher Icons**: Adaptive icon suite (foreground, background, monochrome layers).
- [ ] **Android Notification Icons**: Distinct monochrome silhouette assets.
- [ ] **iOS App Icons**: Complete asset catalog covering required iPhone and iPad resolutions.
- [ ] **Splash / Launch Screens**: Native storyboard or launch assets supporting light/dark system settings.
- [ ] **Deep Links / Universal Links**: Domain association files (`assetlinks.json`, `apple-app-site-association`) and routing handlers.
- [ ] **Notification Privacy**: User permission prompt timing, rationale dialogues, and notification channels.
- [ ] **Store Listing & Compliance**: Privacy labels, permission declarations, Terms of Service, and Privacy Policy.

---

## 4. Desktop Application Identity (if applicable)
- [ ] **App Icons**: Windows `.ico`, macOS `.icns`, and Linux desktop launcher icons.
- [ ] **Window Integration**: Title bar integration, native menus, dock/taskbar behavior, platform keyboard shortcuts.
